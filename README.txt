# Проект Cutefish Dock for KDE (Wayland/Plasma 6)

Цей репозиторій містить всі релевантні скрипти, журнали, лабораторні й довідкові файли, які містилися або використовувалися в Hermes/робочих сесіях для портування та дебагу Cutefish Dock на Qt6/KF6/Wayland (Plasma).

- scripts/: лабораторні і допоміжні скрипти
- experiments/: журнали міграції, аналіз ходу портування
- MIGRATION_LOG.md: перелік переміщень/оригіналів

Початково ініціалізовано з cutefish-statusbar-kde, дублікати переміщено лише один раз (див. MIGRATION_LOG.md).
